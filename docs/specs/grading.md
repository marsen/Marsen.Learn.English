# 批改與成績

系統目前的行為。由 /flow:pbi done 維護。

- 答案設定成只比字母的題目（單選、配對用這種），不分大小寫，也會去掉前後空白（#282）
- 完整考卷的成績頁顯示答對幾題（滿分是實際題數）、每段各對幾題；剛好 40 題才換算雅思聽力級分（估算）；只有一段的考卷不分段、不換算級分（#282）
- 沒登入的路人看得到自己的分數和寫了什麼，看不到正解；頁面上請他免費註冊來看正解（#282）
- 路人登入或註冊後，之前在同一個瀏覽器的作答會移到帳號名下，之後看得到正解，也算進考試紀錄（#282）
- 題組被覆蓋後，舊作答的分數不變，但成績頁的標題和分段改讀新的題組（#282）
