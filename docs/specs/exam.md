# 學生考試

系統目前的行為。由 /flow:pbi done 維護。

- 電腦和手機寬度（390px）都能用，整頁不會橫向捲動（#286、#289）
- 開始考試前會看到考試長度、題數、段數，可以先試音量（#286）
- 完整考卷分成 Section 1、2、3、4 加交卷頁，學生可以自己前後翻；每頁只顯示這一段的題目（#289）
- 錄音開始後只能往前播，不能暫停、倒退、拖動進度或跳段；翻頁不會讓錄音停下或跳走；畫面上有進度條，只顯示不能拖（#282、#289）
- 畫面上看得出錄音現在播到第幾段，以及學生正在看第幾段；錄音播到下一段時，頁面不會自己換（#286、#289）
- 單選用單選鈕，配對用下拉選單，選單裡看得到每個選項的內容（#282、#286）
- 答案存在學生自己的瀏覽器，重新整理後還在；開始新的考試、或考試中登出時，會清掉這份暫存（#285、#289）
- 考試中要離開頁面會先提醒，可以選擇留下；iPhone Safari 上重新整理、關分頁不會提醒（瀏覽器限制）（#285）
- 交卷按鈕只在最後一頁；按下去會再確認一次，並列出各段還有幾題沒填，點了可以回到那一段；錄音播完會自動交卷，不再確認（#285、#289）
