# 題組：上傳與列表

系統目前的行為。由 /flow:pbi done 維護。

- 管理員可以上傳只有 Section 1 的題組（2.x），也可以上傳完整考卷（3.0，1 到 4 段，題數照檔案寫的）；一次上傳整個請求上限 20 MB（#282）
- 完整考卷上傳前先檢查：單選的答案要是選項之一、配對的選項要比題目多至少 2 個、錄音雜湊要對得上、逐字稿和時間軸要對得上，另外段號、題號不能重複，單選剛好 3 個選項，每段出題驗證要通過、AI 審稿結論要是通過或待人工確認，錄音至少 10 KB；任何一項不符就拒收。只要有一段沒有逐字稿，整份逐字稿都不收，但題組照樣收下（#282）
- 同一個 set_id 重新上傳，要按「覆蓋」才會蓋掉原本的題組，沒按只會回報已經存在；覆蓋後題組回到待審、自動下架，目前的審稿結果清掉（審稿紀錄保留），舊的考試紀錄和分數不變（#282）
- 完整考卷在題組列表和審稿頁的代號旁標「完整考卷」；代號本身不改（#286）
- 考卷列表的標題照上傳檔案原樣顯示（程式不改字）；完整考卷在標題後面接「完整考卷（N 段・M 題）」，下一行列出各段的標題；只有一段的考卷接「Section 1・M 題」（#286）
- 後台不顯示「學生考不考得到」的標示（#286）
- 誰考得到：公開考卷全站只有一份，誰都能考，不看審稿狀態；會員考卷要審過合格才考得到；下架的誰都考不到。新上傳的題組一律待審、下架（#282）
