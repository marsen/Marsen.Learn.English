# 題組：上傳與列表

系統目前的行為。由 /flow:pbi done 維護。

- 管理員可以上傳只有 Section 1 的題組（2.x），也可以上傳四段 40 題的完整考卷（3.0）；上傳上限 20 MB（#282）
- 完整考卷上傳前先檢查：單選的答案要是選項之一、配對的選項要比題目多至少 2 個、錄音雜湊要對得上、逐字稿和時間軸要對得上；任何一項不符就拒收（#282）
- 同一個 set_id 重新上傳會覆蓋原本的題組，舊的考試紀錄和分數不變（#282）
- 完整考卷在題組列表和審稿頁的代號旁標「完整考卷」；代號本身不改（#286）
- 考卷列表的標題不寫 Section 幾；完整考卷顯示「完整考卷（4 段・40 題）」，下一行列出四段的標題；只有一段的考卷標「Section 1」（#286）
- 後台不顯示「學生考不考得到」的標示（#286）
