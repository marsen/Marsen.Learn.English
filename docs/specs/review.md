# 老師審稿

系統目前的行為。由 /flow:pbi done 維護。

- 電腦和手機寬度（390px）都能用，整頁不會橫向捲動（#286、#288）
- 完整考卷的審稿頁分成 Section 1、2、3、4、總結五個分頁；每頁只顯示這一段的題目、AI 意見和逐字稿；只有一段的考卷維持原本的樣子（#288）
- 單選、配對題列出選項、正確答案和依據（#282）
- 上方的錄音列有步驟條，每段標出狀態：已完成 ✓、還剩幾項、還沒開始，也提示錄音正在播哪一段；手機寬度收成一行，點開看全部（#288）
- 切換分頁時錄音不會跳；錄音播到下一段時，分頁也不會自己換（#288）
- 每段最上面有可以收起來的小結：這段 OK、有問題、待處理各幾題，加上 AI 對這段整段的意見；OK、有問題、待處理三個數字加起來等於題數（#288）
- 每段有「▶ 從 Section n 開頭播」，按下去從那段的開頭宣讀開始播（#288）
- 一題要算「判過」：判有問題就算；判 OK 的話，這題每則 AI 意見都要標為已處理，而且預設的 OK 要老師再確認一次（#288）
- 考卷上每題的符號：● 還沒判、⚠ 判 OK 但 AI 意見還沒處理、灰色 ✓ 是預設 OK 還沒確認（點一下就確認）、綠色 ✓ 是 OK、紅色 ✗ 是有問題；右側批註欄用「符號 Q3」的短格式，還沒判完的題也會列出來（#288）
- 判完一題會自動收起，下一題自動展開；「下一個待處理」會跨分頁找，需要的話自動切過去（#286、#288）
- 每段底下有「這段完成，前往下一段」：這段每題都判過才按得下去，而且要照段落順序完成；按不下去時列出還沒判的題號，點了會跳過去。回頭改了已完成段落的判定，那段會變回進行中（#288）
- 送出審核只能在總結頁按，四段都完成才按得下去；總結頁並排四段的進度，加上 AI 對整份考卷的意見、總評、合格或不合格（#288）
- AI 審稿意見不能刪，只能標為「已處理」，原文完整保留（#285）
- AI 意見裡寫的位置編號（`t10`、`s1-t10`）會對到逐字稿上同一句，顯示成同樣的寫法（#286）
- 點逐字稿上的時間，錄音會跳到那裡開始播，原本是暫停的也一樣（#288）
- 審到一半的判定、已處理、總評，存在老師自己的瀏覽器裡，重新整理或關掉再開都還在；送出成功才清掉，送出失敗會保留；有暫存時要離開頁面，會先提醒（#288）
