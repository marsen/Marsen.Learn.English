# 老師審稿

系統目前的行為。由 /flow:pbi done 維護。

- 電腦和手機寬度（390px）都能用，整頁不會橫向捲動（#286、#288）
- 完整考卷的審稿頁照實際有的段分頁，最後是總結頁；每頁只顯示這一段的題目、AI 意見和逐字稿；只有一段的考卷維持原本的樣子（#288）
- 單選、配對題列出選項、正確答案和依據（#282）
- 上方的錄音列有步驟條，每段標出狀態：已完成 ✓、還剩幾項、待按完成（都判完了，還沒按「這段完成」）、還沒開始，也提示錄音正在播哪一段；手機寬度收成一行，點開看全部（#288）
- 切換分頁時錄音不會跳；錄音播到下一段時，分頁也不會自己換（#288）
- 每段最上面有可以收起來的小結：這段 OK、有問題、待處理各幾題，加上 AI 對這段整段的意見；OK、有問題、待處理三個數字加起來等於題數（#288）
- 每段有「▶ 從 Section n 開頭播」，按下去從那段的開頭宣讀開始播（#288）
- 一題要算「判過」：判有問題就算；判 OK 的話，這題每則 AI 意見都要標為已處理或改寫過，而且預設的 OK 要老師再確認一次（#288）
- 考卷上每題的符號：● 還沒判、⚠ 判 OK 但 AI 意見還沒處理、灰色 ✓ 是預設 OK 還沒確認（點一下就確認）、綠色 ✓ 是 OK、紅色 ✗ 是有問題；右側批註欄用「符號 Q3」的短格式，還沒判完的題也會列出來。⚠ 和灰色 ✓ 只有完整考卷有；螢幕寬度 1280px 以上，批註欄才排在考卷旁邊（#288）
- 完整考卷判完一題會自動收起，同一段的下一題自動展開；「下一個待處理」會跨分頁找，需要的話自動切過去（#286、#288）
- 每段底下有「這段完成，前往下一段」：這段每題都判過才按得下去，而且要照段落順序完成；按不下去時列出還沒判的題號，點了會跳過去。回頭改了已完成段落的判定，那段會變回進行中（#288）
- 送出審核只能在總結頁按，每段都完成、而且整份考卷判過 OK 或有問題才按得下去；總結頁並排各段的進度，加上 AI 對整份考卷的意見、總評，以及程式算出的合格或不合格（任何一題或整份有問題就不合格），並列出還沒處理的 AI 意見（不擋送出）（#288）
- AI 審稿意見不能刪，只能標為「已處理」或改寫；改寫後原文收在「看 AI 原文」裡，完整保留（#285）
- AI 意見裡寫的位置編號（`t10`、`s1-t10`）會對到逐字稿上同一句，顯示成同樣的寫法；完整考卷整份考卷的意見只寫 `t10` 時對不到（不知道是哪一段）（#286）
- 點逐字稿上的時間，錄音會跳到那裡開始播，原本是暫停的也一樣；點 AI 意見裡的時間只跳過去，不會開始播（#288）
- 審到一半的判定、已處理、總評，存在老師自己的瀏覽器裡，重新整理或關掉再開都還在；送出成功才清掉，送出失敗會保留；有暫存時要離開頁面，會先提醒。暫存之後這份考卷在別處送出過審核、或被重新上傳覆蓋，暫存會作廢並提示（#288）
