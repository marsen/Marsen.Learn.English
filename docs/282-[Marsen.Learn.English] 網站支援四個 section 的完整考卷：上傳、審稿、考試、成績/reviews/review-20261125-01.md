## 資安檢查（#285 AC-4 動到誰能刪改紀錄；`auth.ts` 有改）

- **登入**：`loginRequestState` 只在開發模式（`DevMailer`，沒有 `RESEND_API_KEY`）被重寄冷卻擋下時帶回登入碼。正式環境沒設 `RESEND_API_KEY` 會在啟動時直接失敗（`authContainer.ts:35`），`devLoginCodeFor` 回 null，不會外露。驗證登入碼、session 都沒改
- **授權**：`permission.ts`、`requirePermission`、審稿與考試的 Server Action 權限沒改；審稿頁多傳 `accountId` 只用來當瀏覽器暫存的 key
- **AI 意見不能刪**：只能「標為已處理」，AI 原文完整顯示；原文存在題組的出處資料，老師的動作不會改到它
- **瀏覽器暫存**：考試答案（`exam-draft:` 開頭）、審稿暫存（`review-draft:<帳號>:<題組>`）只存在使用者自己的瀏覽器，沒有敏感資料；開新考試、考試中登出會清掉舊的考試答案
- **上傳**：3.0 先用 Zod 檢查（`fullExamJsonSchema`），單選答案、配對選項數、錄音雜湊、逐字稿和時間軸對不上都擋下，有測試
