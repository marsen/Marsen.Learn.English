# 路人 → 從首頁直接進入公開考卷開始寫

**日期**：2026-11-09
**想法**：#261

## 互動關係

**情境**：路人第一次來到首頁，按任何一個「Full test」按鈕（導覽列、主視覺、示意題做完之後），想馬上寫一張完整的考卷，不用自己挑。

```gherkin
Scenario: 有公開考卷
  Given 題組 A 是公開
  When 路人在首頁按任何一個 Full test 按鈕
  Then 直接進入題組 A 的考卷頁，可以開始寫

Scenario: 沒有公開考卷
  Given 全站沒有公開的題組
  When 路人在首頁按 Full test 按鈕
  Then 進入考卷清單頁（跟現在一樣）

Scenario: 管理員換了公開考卷
  Given 題組 A 原本是公開，管理員改成題組 B
  When 路人重新整理首頁再按 Full test
  Then 進入題組 B 的考卷頁
```

**業務規則**

- 首頁上所有導向 Full test 的連結都指向同一張公開考卷
- 登入的會員在首頁按 Full test，也是進同一張公開考卷
