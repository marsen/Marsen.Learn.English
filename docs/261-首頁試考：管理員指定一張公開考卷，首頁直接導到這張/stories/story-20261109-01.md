# 管理員 → 指定一張題組當作全站唯一的公開試考卷

**日期**：2026-11-09
**想法**：#261

## 互動關係

**情境**：管理員想讓路人一進首頁就能寫一張完整的考卷，在題組清單挑一張設成「公開」。

```gherkin
Scenario: 設定第一張公開考卷
  Given 目前沒有公開的題組
  When 管理員把題組 A 設為公開
  Then 題組 A 是公開
  And 後台看得出題組 A 是首頁試考用的那張

Scenario: 換一張公開考卷
  Given 題組 A 是公開
  When 管理員把題組 B 設為公開
  Then 設定前提示「會取代目前公開的題組 A」
  And 確認後題組 B 是公開、題組 A 改為會員
  And 全站同時只有一張公開

Scenario: 待審的題組也能公開
  Given 題組 C 還沒通過老師審稿（待審或退回）
  When 管理員把題組 C 設為公開
  Then 題組 C 是公開，路人和會員都能寫
  And 後台照樣顯示它的審稿狀態

Scenario: 取消公開
  Given 題組 A 是公開
  When 管理員把題組 A 改成會員或下架
  Then 全站沒有公開的題組
```

**業務規則**

- 公開由管理員決定，暫時不需要通過老師審稿
- 會員考卷的規則不變：要通過老師審稿才能寫
- 被取代的公開題組改為「會員」；它若沒通過審稿，學生暫時還是寫不到
