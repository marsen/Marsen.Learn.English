## 對照 AC-3

| 情況 | 結果 |
|---|---|
| 重新整理、點選單、上一頁離開後回到考試頁 | 用暫存答案交卷 → 成績頁 `?left=1` 顯示離開說明 |
| 一題沒填就離開 | 開始考就存空暫存，回來一樣交卷 |
| 換了帳號、作答找不到 | 丟掉暫存，照常顯示考試說明 |
| 網路錯誤 | 暫存留著，下次再交 |
| 考試中登出 | 照舊清暫存，不交卷（不變） |
| F5、Ctrl+R、⌘R | 先跳「這個行為會直接交卷」，確定才重新整理 |
| iPhone Safari | 擋往下拉重新整理；網址列重新整理沒有提醒，回來就交卷 |

## 資安檢查

- 暫存的 `attemptId` 來自瀏覽器，可以被改；交卷時伺服器照舊用 `ownsAttempt` 檢查是不是本人的作答，不是就回 `not_found`，前端丟掉暫存。拿別人的 `attemptId` 交不了
- 成績頁 `?left=1` 只多顯示一句說明，不影響權限，誰加都一樣
- 暫存只有答案，沒有敏感資料（同原本）
