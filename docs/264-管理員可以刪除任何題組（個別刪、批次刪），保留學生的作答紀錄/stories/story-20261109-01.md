# 管理員 → 刪除沒用的題組（單筆或一次多筆），學生的成績照樣看得到

**日期**：2026-11-09
**想法**：#264

## 互動關係

**情境**：管理員發現有些題組品質太差、重複或已經被新版取代，想把它們從網站上拿掉。可能是看某一套的內容時決定刪，也可能是在題組清單裡一次清掉好幾套。

```gherkin
Scenario: 在題組頁刪一套
  Given 管理員在題組 A 的頁面
  When 按「刪除」
  Then 先確認，寫出題組 A 有幾個人寫過
  And 確認後題組 A 和錄音都刪掉，回到題組清單

Scenario: 在題組清單一次刪多套
  Given 管理員在題組清單勾了題組 A、B、C
  When 按「刪除選取的 3 套」
  Then 先確認，寫出會刪幾套、其中幾套有人寫過
  And 確認後 A、B、C 都刪掉，清單上看不到

Scenario: 刪掉有人寫過的題組
  Given 學生寫過題組 A
  When 管理員刪掉題組 A
  Then 學生的考試紀錄還在，標題改顯示題組代號
  And 成績頁照樣看得到分數和每題的對錯

Scenario: 刪掉公開題組
  Given 題組 A 是公開（免費試卷）
  When 管理員刪掉題組 A
  Then 首頁的免費試卷改導到考卷清單
  And 管理員看到「沒有公開題組」的警告

Scenario: 不是管理員
  Given 老師在題組清單或題組頁
  Then 看不到勾選框和刪除按鈕
```

**業務規則**

- 任何狀態都能刪（待審、通過、退回），有沒有人寫過都一樣
- 刪了就不能復原
- 審稿紀錄保留，老師的費用照算
